# Project Images

## How to Add Your Project Screenshots

Place your project images in this folder with the following names:

1. **cemetery-kiosk.png** - Screenshot of the Cemetery Kiosk Navigation System
2. **barbershop-booking.png** - Screenshot of Brilliante Barbershop Booking System (optional)
3. **apartment-management.png** - Screenshot of FJA Apartment Management System (optional)

## Current Setup

- The Tomb Navigation project is configured to use `/images/cemetery-kiosk.png`
- Save your cemetery kiosk screenshot with this exact filename
- Supported formats: PNG, JPG, JPEG, WebP

## Instructions

1. Save your cemetery kiosk screenshot as `cemetery-kiosk.png` in this folder
2. The image will automatically appear in your portfolio
3. Recommended size: 800x600 or similar aspect ratio for best display
